
# Into The Fasheon

**Group Members:** Hunter and Ollin

## Description

This is a fast-paced action game where you fight your way through powerful fast fashion corporations to stop their environmental damage. As you climb each floor, you defeat enemies and collect different outfits, each with unique abilities and trade-offs. Some outfits give you strong combat power but harm your health over time, while others are sustainable and safer but less powerful. The fun comes from building different outfit combinations, experimenting with strategies, and balancing strength with sustainability while battling increasingly difficult enemies.

## How to Install & Play

The easiest way to play is to download the latest release zip from GitHub, unzip it, and double-click the included executable. No Python, Arcade, or VS Code install is needed.

Windows:
- Latest release page: [Releases](https://github.com/olling2028-dot/cs10-game-Upcycle-Game/releases)
- Direct download: [UpcycleGame-Windows.zip](https://github.com/olling2028-dot/cs10-game-Upcycle-Game/releases/latest/download/UpcycleGame-Windows.zip)
- Or build locally with `build_exe.ps1`

If you want the game to launch from a link on the repo page, GitHub still cannot run a Python/Arcade desktop game directly in the browser without a full web rewrite. The release zip is the desktop-friendly option.

## Make a release

1. Push a tag like `v1.0.0`.
2. GitHub Actions builds `dist/UpcycleGame/` and zips it.
3. GitHub publishes the zip as the latest release download.
4. After that, the direct download link above should work.
